# Prabhanjan P - Resume Website

Welcome to my personal resume website! This is a clean, modern portfolio showcasing my skills, experience, projects, and education.

## 🌐 Live Site

Visit: https://prabhanjanp2012-ops.github.io

## 📋 Features

- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Modern Styling** - Clean and professional gradient header with smooth animations
- **Well-Organized Sections** - About, Experience, Skills, Projects, Education, and Certifications
- **Easy to Customize** - Simply edit `index.html` and `styles.css` to personalize your resume

## 📝 How to Customize

### 1. Edit Your Information
Open `index.html` and update:
- Your name and tagline
- Contact information (email, GitHub, LinkedIn, phone)
- About section
- Work experience
- Skills
- Projects
- Education
- Certifications

### 2. Modify Colors (Optional)
To change the color scheme, edit `styles.css` and replace the color codes:
- Primary color: `#667eea` (purple-blue)
- Secondary color: `#764ba2` (purple)

### 3. Add Your Links
Update these with your actual links:
- Email: `mailto:your.email@example.com`
- GitHub: `https://github.com/prabhanjanp2012-ops`
- LinkedIn: `https://linkedin.com/in/yourprofile`
- Phone: `tel:+1234567890`
- Project links

## 🚀 Deployment

Your site is automatically deployed to GitHub Pages! Just push changes to your repository and they'll be live within minutes.

## 📱 Mobile Responsive

The site includes responsive breakpoints for:
- Desktop (768px+)
- Tablet (480px - 768px)
- Mobile (< 480px)

## 🎨 Customization Tips

- **Add images**: Create an `images/` folder and reference them in HTML
- **Change fonts**: Modify the `font-family` in `styles.css`
- **Add more sections**: Copy an existing section div and customize it
- **Dark mode**: Add a dark mode toggle in the CSS
